# 🚀 Chat AI API

[English version](./readme.md) | [Frontend Repository](https://github.com/DavidSulava/vue-chat-ai-ui)

Надёжный, готовый к продакшену Node.js бэкенд для экосистемы Chat AI. Построен на **Express** и **TypeScript**, это API выступает в роли оркестрационного слоя между сервисами реального времени, реляционным хранилищем и продвинутыми AI-моделями.

---

## ✨ Возможности и технологический стек

*  **Express & [TypeScript](https://www.typescriptlang.org/)** — Масштабируемая архитектурная основа со строгой типизацией.
*  **[Stream Chat API](https://www.getstream.io)** — Бесшовная оркестрация чата, история сообщений в реальном времени и синхронизация состояния пользователей.
*  **[Google Gemini AI](https://aistudio.google.com/)** — Работает через официальный SDK `@google/genai` для интеллектуальных контекстуальных взаимодействий.
*  **[Neon PostgreSQL](https://www.neon.tech) и [Drizzle ORM](https://orm.drizzle.team/)** — Облачная serverless реляционная база данных с типобезопасными запросами и лёгкими миграциями.
*  **Безопасность и производительность**:
    * **JWT Аутентификация**: Безопасное управление пользователями через `jsonwebtoken`.
    * **Хеширование паролей**: Криптографические соляные раунды с помощью `bcrypt`.
    * **Ограничение запросов**: Защита от DDoS и brute-force атак через `express-rate-limit`.
    * **Валидация данных**: Строгая проверка схемы выполнения через `zod`.
*  🧪 **Тестирование и качество**: Полностью покрыто модульными тестами `vitest` и стилизацией кода `eslint`.
